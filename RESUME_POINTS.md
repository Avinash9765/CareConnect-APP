# CareConnect — Resume Bullet Points

- Engineered a full-stack social impact platform, **CareConnect**, using **React.js**, **Node.js**, **Express.js**, and **MongoDB** to bridge the gap between food donors and orphanages.
- Architected a location-based food matching system utilizing **MongoDB Geospatial Queries** and the **Geolocation API** to connect donors with the nearest NGOs in real-time.
- Implemented a robust **JWT-based Authentication** system with role-based access control (RBAC), distinguishing workflows for food donors, NGO partners, and system administrators.
- Designed an interactive **Impact Dashboard** with dynamic data visualizations using **Chart.js**, featuring live activity feeds and real-time statistics of meals donated and lives impacted.
- Developed an automated **Expiry Safety Tracking** system with live countdown timers and real-time notifications to ensure only fresh, safe food is distributed to beneficiaries.
